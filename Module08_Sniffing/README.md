# Module 08 - Sniffing

**In one line.** Capture and read network traffic, and understand how attackers get in the middle.

**Why it matters.** Cleartext protocols still leak credentials; understanding capture is core to both attack and defence.

**Key concepts.** Passive sniffing, ARP spoofing, man-in-the-middle, promiscuous mode, cleartext vs encrypted protocols.

**Core tools.** Wireshark, tcpdump, Ettercap, Bettercap.

**Practise in your lab.** Capture traffic on your lab network, spot a cleartext login, then repeat over HTTPS and see the difference.

**Defender's view.** Encryption everywhere, dynamic ARP inspection, and network segmentation.
