# Module 04 - Enumeration

**In one line.** Pull detailed, named information out of the services you found.

**Why it matters.** Enumeration turns "port 445 open" into usernames, shares and versions - the specifics you actually attack.

**Key concepts.** Banner grabbing, SMB/NetBIOS, SNMP, LDAP, SMTP and NFS enumeration.

**Core tools.** enum4linux, smbclient, snmpwalk, ldapsearch, rpcclient, Nmap NSE scripts.

**Practise in your lab.** Enumerate SMB shares and users on your Windows or Metasploitable target, and list what you would use next.

**Defender's view.** Least privilege, disable anonymous access, restrict SNMP/LDAP exposure.
