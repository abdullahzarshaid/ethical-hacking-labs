# Module 18 - IoT and OT Security

**In one line.** The weak spots of connected and industrial devices.

**Why it matters.** IoT and OT devices are everywhere, rarely patched, and often trivially exploitable.

**Key concepts.** Default credentials, exposed services, firmware analysis, weak protocols (MQTT, Telnet), OT/ICS basics.

**Core tools.** Shodan, binwalk, firmware-mod-kit, Nmap, MQTT clients.

**Practise in your lab.** Extract and inspect a firmware image with binwalk, and find hardcoded secrets or default credentials.

**Defender's view.** Change defaults, segment IoT networks, patch or replace devices, and disable unused services.
