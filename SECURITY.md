# Security policy

This repository contains documentation and client-side or local tooling only. Nothing here runs on your systems unattended, and the published pages send no data anywhere.

If you find a problem that affects the safety of anyone using this material (for example a page that leaks data, a broken security control in a tool, or guidance that is wrong in a way that could cause harm), please report it privately to abdullahbinzarshaid@gmail.com with the page or file, what you observed, and how to reproduce it. You will get an acknowledgement within five working days. Please do not open a public issue for a security problem until it has been addressed.
