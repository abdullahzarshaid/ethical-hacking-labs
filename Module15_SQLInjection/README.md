# Module 15 - SQL Injection

**In one line.** Read and manipulate a database through unsafe queries, then fix it properly.

**Why it matters.** SQL injection is old but still devastating; understanding it teaches you parameterization and defence in depth.

**Key concepts.** In-band and error-based, blind (boolean and time), union-based, stacked queries, out-of-band.

**Core tools.** sqlmap (learn it by hand first), Burp Suite, a lab database.

**Practise in your lab.** Exploit DVWA's SQLi levels manually, then with sqlmap, then rewrite the query with parameters and watch it fail.

**Defender's view.** Parameterized queries/prepared statements, least-privilege database accounts, a WAF, and input validation.
