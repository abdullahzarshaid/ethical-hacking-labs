# Module 19 - Cloud Security

**In one line.** Cloud misconfigurations and the shared-responsibility model.

**Why it matters.** Most cloud breaches are misconfiguration, not zero-days - and this is a top hiring skill right now.

**Key concepts.** Shared responsibility, IAM, public storage buckets, over-permissive roles, metadata SSRF, misconfiguration scanning.

**Core tools.** ScoutSuite, Prowler, the cloud CLIs, trivy, an AWS/Azure free tier.

**Practise in your lab.** Stand up a deliberately misconfigured bucket or role in a free tier, find it with ScoutSuite, then fix it.

**Defender's view.** Least-privilege IAM, configuration baselines, cloud posture management, and logging.
