# Module 16 - Wireless Attacks

**In one line.** Attack and assess Wi-Fi - encryption, capture and rogue access points.

**Why it matters.** Wireless is a physical attack surface that most assessments miss.

**Key concepts.** WEP/WPA2/WPA3, handshakes, PMKID, deauthentication, evil twin, rogue AP, 802.1X.

**Core tools.** The aircrack-ng suite, hcxdumptool, wifite, Wireshark (needs a monitor-mode adapter).

**Practise in your lab.** On your own test access point, capture a handshake and study the crack process, then set up and detect an evil twin.

**Defender's view.** WPA3, strong pre-shared keys or 802.1X, protected management frames, and rogue-AP detection.
