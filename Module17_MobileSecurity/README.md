# Module 17 - Mobile Security

**In one line.** The Android/iOS attack surface and mobile-app security basics.

**Why it matters.** Mobile is where users and data increasingly live.

**Key concepts.** App permissions, insecure storage, traffic interception, reverse engineering APKs, OWASP MASVS.

**Core tools.** An Android emulator, MobSF, apktool, jadx, Burp Suite for mobile traffic.

**Practise in your lab.** Analyse a test APK with MobSF, intercept its traffic, and inspect its local storage.

**Defender's view.** Secure storage, certificate pinning, code obfuscation, and least permissions.
