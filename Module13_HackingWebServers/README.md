# Module 13 - Hacking Web Servers

**In one line.** Attack the web-server layer - misconfigurations, default credentials and known CVEs.

**Why it matters.** The server behind the app is a target in itself and often the weakest link.

**Key concepts.** Server fingerprinting, directory traversal, misconfiguration, default creds, known-CVE exploitation, WebDAV.

**Core tools.** Nikto, gobuster/dirb, Nmap http NSE scripts, searchsploit, Metasploit.

**Practise in your lab.** Fingerprint a lab web server, enumerate its directories, and exploit a known server vulnerability.

**Defender's view.** Patching, hardening, removing defaults, least privilege, and a WAF.
