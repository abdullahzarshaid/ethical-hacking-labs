# Module 03 - Scanning

**In one line.** Discover which hosts are alive and which ports and services are open.

**Why it matters.** You cannot attack what you cannot see. Scanning turns an IP range into a map of reachable services.

**Key concepts.** Host discovery, TCP/UDP scanning, SYN vs connect scans, service/version and OS detection, timing and stealth.

**Core tools.** Nmap (master this one), masscan, netdiscover.

**Practise in your lab.** Run host discovery on your lab subnet, then a full port + service-version scan on a target, and read the output carefully.

**Defender's view.** Firewalls, closing unused ports, and IDS to spot scans.
