# Module 12 - Evading IDS, Firewalls and Honeypots

**In one line.** Understand how detection works, and how attackers try to slip past it.

**Why it matters.** Knowing evasion makes you a better defender - you tune detection by knowing how it is beaten.

**Key concepts.** Signature vs anomaly detection, fragmentation, obfuscation, tunnelling, timing, honeypots.

**Core tools.** Nmap evasion flags, Snort/Suricata (to watch detection), proxychains.

**Practise in your lab.** Run a noisy scan and watch Snort/Suricata alert, then apply evasion flags and compare.

**Defender's view.** Layered detection, anomaly baselines, decoys/honeypots, and log correlation.
